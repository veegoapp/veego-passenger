Investigation Report
Root Cause
The tab bar is position: absolute, bottom: 0, zIndex: 99. Its total rendered height from the bottom of the screen is insets.bottom + 72px (4px top padding + 12px navInner vertical padding + 16px navItem vertical padding + 32px content + 8px extra above safe area).

All bottom-anchored sheets inside the tab screens use paddingBottom: insets.bottom + 16/35, which only clears the device safe area — not the tab bar above it. This leaves 37–56px of bottom content hidden behind the tab bar.

The existing TabBarContext already has a visible toggle but no measured height — components have no shared way to know how tall the bar is.

Fix Strategy
Extend TabBarContext with a measured tabBarHeight (set via onLayout on the tab bar root view). This is one change point and works across all screen sizes automatically.
