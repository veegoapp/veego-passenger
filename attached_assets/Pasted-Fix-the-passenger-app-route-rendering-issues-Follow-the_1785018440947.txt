FIX 1 — Primary Bug: Passenger tracking draws straight line instead of Google route
==================================================

Problem:
Car ride tracking in the passenger app shows a straight polyline between locations even though Google Directions API is available.

Root cause:
components/shared/PassengerTrackingMap.native.tsx only calls fetchGoogleRoute when stations exist.
This works for shuttle trips, but car rides do not have stations, causing the component to skip Google Directions and use fallback straight-line coordinates.

Required changes:
- Keep the existing shuttle route logic exactly as it is.
- Add a separate route handling path for non-shuttle rides when stations is empty.
- When:
    - driverLocation exists
    - dropoff exists
    - stations array is empty
  then call the existing fetchGoogleRoute utility.

For car rides:
- origin should be driverLocation.
- destination should be dropoff.
- Use the returned Google route coordinates for Polyline.
- Only use straight-line fallback if Google route fails.

Do not change the visual design of the map.
